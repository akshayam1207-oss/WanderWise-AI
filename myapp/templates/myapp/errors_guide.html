⭐ Site-Specific Code: WW-600 (Application Status 600)

Meaning: WanderWise AI Travel Plan Generation Quota Exceeded / AI Destination Planner Timeout.
This site-specific error code is unique to WanderWise AI and stored in the SQL database. It triggers when an itinerary request exceeds safe duration limits (> 30 days) or when multi-city constraints overwhelm real-time route optimization algorithms.
